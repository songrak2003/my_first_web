🎨 처음 만나는 CSS

HTML이 뼈대라면, CSS는 옷과 화장입니다. 색과 모양을 마음대로 바꿔봐요.

CSS란? 적용 방법 선택자 글자·색 박스 모델 배치 마우스 효과 직접 해보기

1. CSS란?

CSS(Cascading Style Sheets)는 웹페이지의 겉모습을 꾸미는 언어입니다. 글자 색, 크기, 배경, 간격, 배치를 정해요.

CSS의 기본 문장은 이렇게 생겼습니다.

선택자 {
  속성: 값;
  속성: 값;
}

"어떤 것을 { 무엇을: 어떻게 }" 라고 읽으면 됩니다. 각 줄 끝에는 세미콜론 ;을 꼭 붙이세요.

h1 {
  color: red;        ← 글자색을 빨강으로
  font-size: 40px;   ← 글자 크기를 40픽셀로
}

→ "모든 <h1>의 글자색은 빨강, 크기는 40px로 해라"

2. HTML에 CSS 붙이는 방법

세 가지가 있지만, 초보자는 ①번과 ②번만 알면 충분합니다.

① <style> 태그 안에 쓰기 (이 페이지가 쓰는 방식)
<head>
  <style>
    h1 { color: red; }
  </style>
</head>
② 별도 파일로 만들어 연결하기 (실무에서 가장 많이 사용)
<!-- HTML 파일의 head 안에 -->
<link rel="stylesheet" href="style.css">

/* style.css 파일 안에는 CSS만 적어요 */
h1 { color: red; }
③ 태그에 직접 쓰기 (간단히 한 번만 쓸 때)
<p style="color: red;">빨간 글씨</p>

빨간 글씨

3. 선택자: "누구를 꾸밀까?"

① 태그 이름으로 선택 → 그 태그 전부
h3 { color: crimson; }
p  { color: #2563eb; background: #fef9c3; }

제목입니다

문단입니다

② 클래스(.) → 여러 개에 이름표를 붙여서 선택
<span class="big">큰 글씨</span>
<span class="small">작은 글씨</span>

.big   { font-size: 28px; font-weight: bold; }
.small { font-size: 12px; color: gray; }
큰 글씨 작은 글씨
③ 아이디(#) → 딱 하나에만 붙이는 고유 이름표
<span id="unique">나만의 스타일</span>

#unique { color: white; background: #7c3aed; }
나만의 스타일
💡 점(.)은 클래스, 샵(#)은 아이디. 이름표를 여러 곳에 쓰려면 클래스를 쓰세요.

4. 글자와 색

속성하는 일예시 값
color글자색red, #ff0000, rgb(255,0,0)
background배경색yellow, #fef9c3
font-size글자 크기20px, 1.5rem
font-weight굵기bold, normal
text-align글자 정렬left, center, right
💡 색은 이름(red), 16진수 코드(#ff0000)로 쓸 수 있어요. 구글에서 "color picker"를 검색하면 원하는 색의 코드를 쉽게 찾을 수 있습니다.

5. 박스 모델: 모든 요소는 상자다

웹페이지의 모든 요소는 네모난 상자입니다. 상자는 바깥에서 안쪽으로 이렇게 구성돼요.

  • margin (바깥 여백): 다른 상자와의 거리
  • border (테두리): 상자의 선
  • padding (안쪽 여백): 테두리와 내용 사이 거리
  • 내용 (content): 글자나 이미지
.box {
  width: 200px;
  background: #bae6fd;
  border: 4px solid #0284c7;
  padding: 20px;
  margin: 20px;
}
내용이 들어가는 상자
💡 padding을 키우면 상자 안이 넓어지고, margin을 키우면 상자 밖이 넓어집니다. 직접 해보기에서 숫자를 바꿔 보세요!

6. 나란히 배치하기 (Flexbox)

상자를 가로로 나란히 놓고 싶을 때 가장 쉬운 방법은 display: flex입니다. 부모 상자에 적어요.

.flex-demo {
  display: flex;
  gap: 10px;                    /* 상자 사이 간격 */
  justify-content: space-around; /* 가로 정렬 방식 */
}

7. 마우스를 올리면 변하는 효과

:hover를 선택자 뒤에 붙이면 "마우스를 올렸을 때"의 모양을 정할 수 있습니다.

button {
  background: #ec4899;
  transition: all .25s;   /* 부드럽게 변하게 */
}
button:hover {
  background: #7c3aed;
  transform: scale(1.1);  /* 1.1배 커지게 */
}
