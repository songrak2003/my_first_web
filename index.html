1. HTML이란?

HTML은 웹페이지의 내용과 구조를 적는 언어입니다. "여기는 제목이고, 여기는 문단이고, 여기는 사진이야"라고 브라우저에게 알려주는 표시라고 생각하세요.

집으로 비유하면 HTML은 뼈대(기둥·벽·방)입니다. 색칠은 CSS, 움직임은 JavaScript가 맡아요. 우선 뼈대부터 배웁니다.

HTML의 핵심은 태그입니다. 태그는 <와 > 사이에 이름을 적은 것이고, 대부분 여는 태그 + 내용 + 닫는 태그로 이루어집니다. 

<p>안녕하세요</p>
 ↑ 여는 태그   ↑내용   ↑ 닫는 태그 (이름 앞에 / 가 붙어요)

2. 모든 HTML 문서의 기본 뼈대

이 페이지의 맨 위도 아래와 같은 모양으로 시작합니다.

<!DOCTYPE html>          ← "이건 HTML 문서예요" 선언
<html lang="ko">         ← 문서 전체를 감싸는 상자 (한국어)
  <head>                ← 화면에 안 보이는 정보 (설정)
    <meta charset="UTF-8">   ← 한글이 안 깨지게 하는 설정
    <title>내 홈페이지</title> ← 브라우저 탭에 뜨는 이름
  </head>
  <body>                ← 화면에 실제로 보이는 모든 내용
    여기에 내용을 적어요
  </body>
</html>
💡 head는 "머리(설정)", body는 "몸(보이는 내용)"이라고 외우면 쉬워요.

3. 글자 다루기

제목 (h1이 가장 크고, h6이 가장 작아요)
<h1>가장 큰 제목</h1>
<h2>그 다음 제목</h2>
<h3>더 작은 제목</h3>

가장 큰 제목

그 다음 제목

더 작은 제목

문단, 굵게, 기울임, 줄바꿈
<p>이것은 한 문단입니다.</p>
<p><strong>굵은 글씨</strong>와 <em>기울인 글씨</em><br>
줄바꿈도 가능해요.</p>

이것은 한 문단입니다.

굵은 글씨와 기울인 글씨
줄바꿈도 가능해요.

💡 코드에서 엔터를 여러 번 쳐도 화면에서는 줄이 바뀌지 않아요. 줄바꿈은 <br>, 새 문단은 <p>를 써야 합니다. (<br>처럼 내용이 없는 태그는 닫는 태그가 필요 없어요.)

4. 링크와 이미지

태그 안에 속성을 넣어서 추가 정보를 줄 수 있습니다. 모양은 속성이름="값" 입니다.

링크: a 태그 + href 속성(이동할 주소)
<a href="https://www.naver.com" target="_blank">네이버로 가기</a>
네이버로 가기
이미지: img 태그 + src 속성(사진 주소) + alt 속성(사진 설명)
<img src="사진.jpg" alt="귀여운 고양이" width="200">
💡 src의 파일은 HTML 파일과 같은 폴더에 두면 파일 이름만 적어도 됩니다.

5. 목록 만들기

순서 없는 목록 (ul) / 순서 있는 목록 (ol) — 각 항목은 li
<ul>
  <li>사과</li>
  <li>바나나</li>
</ul>

<ol>
  <li>일어나기</li>
  <li>세수하기</li>
</ol>
  • 사과
  • 바나나
  1. 일어나기
  2. 세수하기
표 (table)
<table border="1">
  <tr><th>이름</th><th>나이</th></tr>
  <tr><td>철수</td><td>20</td></tr>
</table>
이름나이
철수20
💡 tr=행(가로줄), th=제목 칸, td=내용 칸.

6. 입력창과 버튼

<label>이름: <input type="text" placeholder="이름을 입력"></label>
<input type="checkbox"> 동의합니다
<button>보내기</button>
